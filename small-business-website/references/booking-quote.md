# Booking and quotes

## WhatsApp booking

- Build the link from the number the owner gave you, in international format without spaces, plus signs, or dashes in the link itself.
- Pre-fill a message with the service and date, for example: `Hi, I'd like to book a haircut on Saturday.`
- Test the link on a phone. It must open WhatsApp with the message ready to send.
- Put the WhatsApp button in the hero and next to the services list.

## Booking form

Ask only what is needed to book:

- Name
- Service (dropdown from the real price list)
- Date and time (or "preferred date")
- Phone number

On submit, show: "Thanks — we will confirm by phone / WhatsApp within [time the owner gives]." If the owner gives no time, say "we will confirm shortly" and do not invent a time.

Do not ask for an account, a password, or payment at booking unless the owner explicitly asks for deposits — and if so, get the deposit rules in writing first.

## Quote calculator

Inputs, 3–5 only:

- Service type
- Size or quantity (rooms, hours, items)
- Frequency, if it changes the price (one-off vs weekly, for example)
- Location or service area, if travel changes the price

Output:

- A price range, labelled "Estimate"
- What is included, and what is not
- A "Send this quote" button that opens WhatsApp or email with the inputs included

Rules:

- Never present an estimate as a fixed price.
- Never hide fees that appear later.
- Show the calculation in plain language, for example "2 bedrooms x standard clean".
- If an input is missing, say what is needed instead of guessing a price.
