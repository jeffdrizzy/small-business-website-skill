# SEO, speed, and deployment

## SEO basics

- Title: business name, what it does, town / area.
- One H1 per page, matching the title.
- Meta description: one sentence a customer would read, with the service and area.
- Business name, address / service area, and phone written the same way everywhere on the site.
- Descriptive file names for images, and alt text.

## Speed

- Compress images. Prefer modern formats where supported, with a fallback.
- No heavy libraries for a simple site. No autoplay video.
- Target: load in under 3 seconds on a phone connection.
- Check before handover on a real phone, not only on desktop.

## Deployment

- Free static hosting: Netlify or GitHub Pages. No server needed for a business site, landing page, or client-side quote tool.
- One live link. Test it in a private browser window.
- If a form is used, confirm where submissions go — email or WhatsApp — and test a submission end to end.

## Handover test

On a phone, check:

- [ ] No sideways scrolling
- [ ] Hero button works
- [ ] Phone number taps to call
- [ ] WhatsApp link opens with the right message
- [ ] Form submits and shows a confirmation
- [ ] Prices, hours, and address are correct
- [ ] Page loads fast
