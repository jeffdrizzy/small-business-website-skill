# Example: Cleaning business — quote tool

Business type: cleaning service. Template: Quote tool. Goal: quote requests.

## Sections

1. Hero: "CleanQuote — Cleaning quotes in 60 seconds." Button: Get my quote.
2. Calculator inputs (3–5 only):
   - Property type: apartment / house / office
   - Bedrooms: 1 / 2 / 3 / 4+
   - Bathrooms: 1 / 2 / 3+
   - Service: standard clean / deep clean / move-out clean
   - Frequency: one-off / weekly / fortnightly
3. Output: "Estimate: [CURRENCY] 80–120 for a 2-bedroom standard clean. Includes [list]. Excludes [list]. This is an estimate, not a final price."
4. Send this quote: WhatsApp or email button, with the inputs included in the message.
5. How it works: 1) Get an estimate, 2) We confirm a time, 3) We clean, you pay after.
6. Example prices: 2–3 real examples supplied by the owner.
7. Contact footer: phone, WhatsApp, service area, hours.

## Pricing logic

- Base price per property type, plus per bedroom / bathroom, plus a deep-clean uplift, minus a frequency discount if the owner offers one.
- Show the maths in plain language under the estimate, for example "Base 50 + 2 bedrooms x 15 = 80".
- Never present the estimate as a fixed price. Never add hidden fees later.
